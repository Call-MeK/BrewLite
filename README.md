# BrewLite

BrewLite là ứng dụng đặt cà phê và thanh toán không dùng tiền mặt,
được xây dựng cho môn Công nghệ Phần mềm.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- TypeScript
- REST API

### Database
- PostgreSQL
